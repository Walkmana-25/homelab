## summary

The homelab uses an ArgoCD "App of Apps" GitOps pattern with two umbrella Applications (`application-infrastructure.yaml`, `application-application.yaml`) that point at kustomize overlays in `argocd/k3s/apps/{infrastructure,application}/`. Each app is a directory containing an `application.yaml` (the ArgoCD Application CR) plus a `kustomization.yaml`, and may bundle SealedSecrets or extra manifests. Apps are deployed three ways: (1) **Helm charts via ArgoCD** (`spec.source.chart` + `repoURL` + inline `helm.values` — the dominant pattern, e.g. dawarich, librechat, grafana, loki, cert-manager), (2) **raw kustomize manifests in-repo** (path-based source pointing to `k8s/apps/*`, e.g. firecrawl, mcp-proxy), and (3) **sub-applications** (an Application whose source is another repo path that creates more Applications, e.g. dawarich-postgres). TLS/ingress is entirely via **Cloudflare Tunnel** (`ingressClassName: cloudflare-tunnel`); there is **no ClusterIssuer / no cert-manager TLS** because Cloudflare terminates TLS at the edge. Storage is split: **`nfs`** (default StorageClass, ReadWriteMany) for shared/bulk data and **`longhorn`** (block, ReadWriteOnce) for databases. Secrets use **Bitnami SealedSecrets** (`bitnami.com/v1alpha1`). Renovate auto-updates ArgoCD Helm apps weekly. No existing Harbor references.

  - `argocd/k3s/apps/infrastructure/cloudflare-tunnel-ingress-controller/cloudflare-tunnel-credentials.yaml` (JSON-formatted SealedSecret)
